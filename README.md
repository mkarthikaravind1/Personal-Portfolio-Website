## 📬 EmailJS Setup

This project uses **EmailJS** to send messages directly from the contact form.

### Steps

1. Create an EmailJS account.
2. Create an Email Service.
3. Create an Email Template.
4. Replace the following values in `script.js`:

```javascript
emailjs.init("YOUR_PUBLIC_KEY");

emailjs.sendForm(
    "YOUR_SERVICE_ID",
    "YOUR_TEMPLATE_ID",
    contactForm
);
```
